# TASK-S001-012 - Validate and Select the New FTT Service

## Objective

Confirm that the new Qwen service supports VNizer page transcription.
Set it as the default FTT service only if it passes the required checks.

## Context

VNizer sends each PDF page as an image through the OpenAI-compatible chat API.
The service must accept image input and return structured page content.

## Dependencies

- `TASK-S001-011`

## Plan

- Find the reachable endpoint and advertised model.
- Test text input, image input, and structured page output.
- Change the default FTT settings only after successful tests.
- Run focused tests and record the result.

## Notes

The deployment log identifies `Qwen3.6-35B-A3B-FP8` and vLLM 0.31.0.
The log also says that the service runs in text-only mode.
The local deployment file publishes container port 8000 on host port 5003.
The model list request advertised `Qwen3.6-35B-A3B-FP8`.
A text chat request returned HTTP 200 and the expected response.
An image chat request returned HTTP 400.
The response said that the prompt can contain at most zero images.
VNizer needs image input because it sends rendered PDF pages to the FTT service.
The service is not suitable for VNizer while `--language-model-only` is active.
The VNizer default FTT service remains unchanged.
