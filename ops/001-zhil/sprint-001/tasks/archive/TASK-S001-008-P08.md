# TASK-S001-008 - Add the external Supertonic TTS service

## Objective

Check the external service and support it as the default deployment TTS resource.
Keep the local Qwen service available.

## Plan

- Read the service contract and run a short speech request.
- Add service selection, audio conversion, and compatible restart checkpoints.
- Create deployment environment settings and document startup commands.
- Check both service adapters and record live experiment results.

## Notes

The external service exposes Supertonic speech as mono PCM16 at 24,000 Hz.
Its request fields are text, voice, and lang.
The voice list is available without credentials.

## Results

The external speech service passed a short English experiment and a complete media render.
The default Docker settings now select Supertonic at `http://10.12.1.249:5001`.
The local database selects the same service for new processes and retries.
Local Qwen remains available. Existing attempts keep their saved settings.
The external adapter converts PCM16 into WAV and separates incompatible speech checkpoints.
The Admin page can select either service type.
The requested `deploy/.env` exists locally and stays outside Git.
Its tracked example contains the same deployment defaults.
