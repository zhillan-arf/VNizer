# TASK-S001-009 - Publish VNizer on reachable host interfaces

## Objective

Make the Docker deployment reachable at the configured host port from other machines.
Explain the host and container port mapping.

## Context

The user's Docker output maps `127.0.0.1:5301` to container port 8080.
The host bind address prevents access through the server network address.

## Plan

- Set the deployment bind address to all host interfaces.
- Document the Compose restart and the meaning of the port mapping.
- Resolve the Compose file and archive this task.

## Notes

The mapping `127.0.0.1:5301->8080/tcp` binds host port 5301 to loopback only.
Host port 8080 can serve another host process without a container port conflict.
