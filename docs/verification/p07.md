The parser request count stays unchanged during the media retry.
Stream inspection confirms audio and video output types.

Additional tests cover parser checkpoints, worker cancellation, parent death, terminal-state preservation, and saved avatar selection.
The release fixes an upload event-handler race, an admin tab race, and a worker shutdown state race.
