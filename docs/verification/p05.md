# P05 verification

## Model preparation

Downloaded both official repositories under `/data-model/zhillan/VNizer`.
The download completed without loading weights on the GPU.
The script checked each upstream LFS SHA-256 or Git blob SHA-1 before accepting the file.
It also recorded SHA-256 for every downloaded file.

- `tts-model-inventory.json`: CustomVoice model revision and file hashes.
- `tts-tokenizer-inventory.json`: tokenizer revision and file hashes.

The local model includes its speech tokenizer files.
The standalone tokenizer is also available for independent deployment checks.
The source model cards retain the publisher's license declaration.

## Media checks

Automated tests render real H.264/AAC MP4 files with fixture WAV responses.
The audio-only output has no video stream.
The visual output has 1280 by 720 dimensions and synchronized audio duration.
Tests check speech reuse, invalid audio, truncated WAV input, and animated avatar input.
These checks validate the integration contract. They do not validate Qwen voice quality.

A rendered frame was inspected at `/tmp/vnizer/p05/frame.png`.
The fallback character, document title, narration, page reference, and mood are visible.
No text overlap was found in that frame.

## TTS wrapper

Contract tests use a model fixture through the actual HTTP application.
They check authentication, health, WAV generation, input limits, speaker validation, and language validation.
The Dockerfile has not been deployed. Live GPU inference remains a user deployment check.
