# P08: External TTS experiment

## Result

On October 4, 2026, VNizer accessed `http://10.12.1.249:5001/docs` and its OpenAPI document.
The API identifies itself as Supertonic TTS + Whisper STT Server.
The external service is usable through the new Supertonic adapter.
Local Qwen remains available through the `qwen` service type.

## Live experiment

The voice list returned HTTP 200 without credentials and included voice F1.
The speech request used F1, language code `en`, and this text:

> This is a VNizer speech test. The table contains three rows and two columns.

`POST /v1/audio/speech` returned HTTP 200 in 1.238 seconds.
It returned 302,948 bytes of mono PCM16 at 24,000 Hz.
The sample contains 6.311 seconds of audio. Its peak sample magnitude is 9,451.
The response included `Content-Type: application/octet-stream` and `X-Sample-Rate: 24000`.

The experiment converted the sample to 16,000 Hz and sent it to the service's Whisper endpoint.
The transcription recovered both sentences. It spelled the product name as “Venizer”.
This check supports intelligibility for this sample. It does not replace a listening check.

A second request used the VNizer adapter and its complete media renderer.
It produced an audio-only MP4 and a visual novel MP4 from one narration chunk.
FFprobe confirmed H.264 video at 1280 by 720 pixels and AAC audio at 24,000 Hz.
The video duration was 3.209 seconds.
This experiment used synthetic narration. It did not parse a PDF.

Temporary requests, audio, and media are under `/tmp/vnizer/`.
The first WAV sample is `/tmp/vnizer/tts-probe.wav`.
No Docker service was deployed.

## Configuration

`deploy/.env` selects port 8080, type `supertonic`, URL `http://10.12.1.249:5001`, and voice F1.
The tracked `deploy/.env.example` preserves these defaults for new checkouts.
The local database now uses these TTS settings for new processes and retries.
Existing attempts retain their saved settings.
The previous settings were saved to `/tmp/vnizer/p08-settings-before.json` with owner-only access.

The adapter converts raw PCM into validated WAV checkpoints.
It preserves request timeouts, size limits, retries, and explicit failures.
Speech checkpoints include the external service type. Existing Qwen checkpoints retain their original identity.

## Limits

The external API does not accept mood instructions. Visual avatar moods remain available.
The voice-list check does not test speech generation or language support.
Only English voice F1 received a live speech check.
Other voices, languages, long documents, and concurrent use still need acceptance checks.
Local Qwen GPU inference was not checked in this phase.
