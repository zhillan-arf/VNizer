# P06 verification

The web interface includes authentication, upload, process, and admin pages.
The pages use the same session. The admin page has no separate role.

## Automated checks

Chromium tests use the real application API with isolated data directories.
They cover these actions:

- Enter without credentials, sign in with credentials, reject a wrong password, and sign out.
- Browse for multiple PDFs and drop a PDF onto the upload area.
- Reject conversion when a required service is unavailable.
- Open a process URL, reload saved state, and retry a failed stage.
- Download an output archive.
- Save service settings.
- Upload, preview, select, and delete an avatar.
- Stop a queued process, delete an artifact, and delete the process.

The tests also check for JavaScript errors and phone-width horizontal overflow.
Service responses are fixtures. Live model quality is not part of these browser checks.

## Corrections

Upload controls now receive event handlers before the recent-process request finishes.
Deleted fallback avatars do not reappear when a custom avatar covers the same mood.
Each running attempt saves its selected avatars before transcription starts.
Avatar snapshots and deletion use database transactions to prevent concurrent file removal.
